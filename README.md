# Fifteen Puzzle

A browser version of the classic sliding-tile **15 puzzle**, built with HTML, CSS, JavaScript and jQuery.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)

## Features

- **Shuffle** scrambles the board into a new puzzle.
- Click a tile next to the empty space to slide it.
- A **move counter and timer** track your progress, and your **best time and moves** are shown after each win.
- Choose from **four background images** for the tiles.
- A celebration animation when you solve the puzzle.
- A **Cheat** button solves the puzzle for you.

## Play

Open `fifteen.html` in any browser. No install needed.
